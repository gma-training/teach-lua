Teaching me Lua
===============

This repository contains HTML files that Claude Code generated for me when I used Matt Pocock's [/teach skill], and asked it to teach me Lua.

I mentioned that:

- I've done a lot of Python, a lot of Ruby, and plenty of JavaScript.
- I want to learn Lua to configure Neovim (using Lua 5.1) and Hyprland (Lua 5.4).

Claude has gone to great lengths to highlight differences between the two versions of Lua, and made some good comparisons between Lua's behaviour, and that of the other languages I already know.

I'm impressed. It's been genuinely useful, and significantly faster than trying to piece together what I needed to know from the official Lua docs.

[/teach skill]: https://www.aihero.dev/skills-teach

Strings

Join, slice, format — and the colon that trips everyone once.

Core habits

You writeWhat happens
"a" .. "b"concatenation — .., never +
"x=" .. 80"x=80" — number coerced to string
"10" + 515 — numeric string coerced to number (not JS's "105")
s:upper()method call — sugar for string.upper(s) (colon passes self)
s:sub(1, 4)chars 1–4 inclusive, 1-based
s:sub(-4)last 4 chars (negative counts from end)
#slength in bytes, not characters

Literals

'single' and "double"   -- interchangeable; both take \n \t \\ escapes
[[ multiline,
verbatim, no escapes ]]  -- long bracket; drops one leading newline
[==[ text with ]] inside ]==]   -- bump the level if the body contains ]]
-- No interpolation: use .. or string.format instead of f"" / ${}

string.format (printf)

string.format("[%s] w=%d %02x", name, 80, 15)
-- %s string · %d integer · %x hex · %02d zero-pad · %f float · %q quoted
Two version notes. UTF-8: Lua 5.4 has a utf8 library (utf8.len for real character counts); Lua 5.1 has none — only bytes via #. %d: on 5.4, string.format("%d", 3.5) errors (no integer representation); on 5.1 it truncates to "3". math.floor the value first to agree across both.

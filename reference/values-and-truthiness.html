Truthiness — the whole rule

Only nil and false are falsy. Everything else is truthy — including 0, 0.0, "", and {}.

ValueLuaRubyPython

Lua truthiness == Ruby truthiness. Python is the odd one out.

Idioms that fall out of the rule

-- default value (like Ruby  x = x || default)
x = x or default

-- ternary  (cond ? a : b)  — works ONLY if a is never falsy
result = cond and a or b

-- presence check: nil means "absent", not "error"
if config.width then ... end

Numbers split by version. Neovim 5.1 every number is a 64-bit float — there is no integer type. Hyprland 5.4 numbers have integer and float subtypes; math.type(x) tells them apart, and 3 // 2 is integer floor division. Truthiness and nil are identical across both versions.

Write-once, runs-in-both idioms

-- floor division that works in BOTH versions:
local q = math.floor(a / b)

-- force a float-looking result everywhere: just use / (never //)
local ratio = w / h

-- integer-ness you can trust only on 5.4; on 5.1 guard it:
if math and math.type then ... end   -- 5.4-only branch
Mental model. Lua 5.4 numbers behave like Python 3: / is float division, // is floor division, integers and floats are distinct. Lua 5.1 has one float type and no // at all — closer to JavaScript's single number type. The safe habit: avoid // and native bitwise unless the code is 5.4-only.

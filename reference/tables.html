Write-once, runs-in-both idioms

-- unpack that works on both versions:
local unpack = table.unpack or unpack
unpack(rgb)

-- keep sequences dense: rebuild rather than nil-ing a middle slot,
-- so # and ipairs stay trustworthy.
Mental model. One table does Python dict + list fused; the hash half is a JavaScript object and dot/bracket access works the JS way. It's 1-based (unlike all of Python/JS/Ruby). The two real 5.1 / 5.4 traps: # is unspecified on holey tables, and unpack is unpack (5.1) vs table.unpack (5.4).
